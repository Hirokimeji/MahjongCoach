# 雀魂新手教练

面向日麻初学者的 Windows 桌面辅助工具。根据实时牌局提供切牌、役种方向和防守参考，支持 Steam 雀魂的三麻与四麻。

## 功能

- 先胡牌、做大牌、先防守、避四四种模式，可随时切换。
- 展示推荐切牌、简短解释、有效进张及未见张数。
- 持续显示手牌放铳风险，高风险推荐可配置提醒门槛。
- 按对手展示听牌估计和危险牌，支持手牌范围与全部牌种。
- 提供立直、吃碰、杠、拔北及和牌提示，展示牌面估分和结算结果。
- 支持置顶、小窗、窗口缩放，以及深色、浅色、粉色主题。
- 支持本地图片背景和可选动态背景。
- 集成 MAX 启动、停止恢复、正式版更新检查，以及仅打牌辅助模式。

## 下载发行版

适用于 Windows 10 / 11 的 x64 电脑。到 [Releases](https://github.com/Hirokimeji/MahjongCoach/releases) 下载 **MahjongCoach-v0.2.2-win-x64.zip**。

发行包内置 Python、PySide6、分析引擎、MAX 和 Live2D 播放依赖。解压完成后双击 **雀魂新手教练.exe**，即可打开界面。请将整个文件夹解压到可写目录，例如 `D:\Games\MahjongCoach`，并保留子文件夹。无需安装 Python、Go 或运行构建命令。

GitHub 自动生成的 Source code 压缩包用于源码开发。使用桌面程序请选择上面的 win-x64.zip 附件。

## 第一次使用

### 1. 准备游戏

在 Steam 安装并更新「雀魂麻将」，先正常启动一次，确认能进入游戏大厅，再退出游戏。

在 Steam 库右键雀魂 → 管理 → 浏览本地文件，记下程序的位置。连接设置中需要选择这里的 `Jantama_MahjongSoul.exe`。

### 2. 安装和打开 Clash Verge Rev

从 [Clash Verge Rev 官方发行页](https://github.com/clash-verge-rev/clash-verge-rev/releases) 下载适合电脑的 Windows x64 安装包，安装后打开。详细安装步骤见 [官方文档](https://www.clashverge.dev/)。

- 已有订阅的用户，在「订阅」中导入并启用配置，确认所选节点能访问雀魂。
- 使用直连的用户，可在「订阅」中导入发行包内的 `Clash-直连示例.yaml` 并启用。该配置的出口是 DIRECT。
- 教练启动期间保持 Clash Verge Rev 运行。Clash 的 TUN 功能需要可用的服务模式，按 Clash 的提示安装或启用服务。

教练目前通过 Clash Verge Rev 的 Windows 命名管道接口控制配置。其他代理客户端和只开放 HTTP 控制接口的安装方式尚未适配。

### 3. 填写连接设置

双击 `雀魂新手教练.exe`，首次打开会显示「连接设置」。也可在大窗左侧或小窗「主题」菜单中重新打开。

| 字段 | 填写方法 |
| --- | --- |
| 雀魂程序 | 点「选择」，找到步骤 1 的游戏 exe |
| Clash 配置目录 | 默认自动填入当前 Windows 用户的配置目录。目录内应有 `clash-verge.yaml` 和 `profiles` 文件夹 |
| MAX 网络出口 | 点「读取代理组」。直连选择 DIRECT，需要代理时选择订阅中的可用代理组 |

默认 Clash 目录为 `%APPDATA%\io.github.clash-verge-rev.clash-verge-rev`。如果使用便携版，在 Clash 内打开实际配置目录后选择该目录。

点击「保存」。设置存储在发行包内的 `MajsoulMax-Steam/launcher.json`，更换电脑、游戏路径或代理组后可以重新填写。

也可以取消设置，先点「示例手牌」查看界面。

### 4. 启动并进入新的一局

1. 确认 Steam 在线、Clash 正在运行。
2. 默认开启「全解锁关闭 · 仅辅助」。可在启动前切换外观模式。
3. 点击「启动雀魂」，等待状态变为提示已开启。
4. 首次启动可能需要下载 MAX 协议数据并建立本地代理证书。MAX 更新失败时，先查看 `MajsoulMax-Steam/max.log`，确认网络出口可访问 GitHub。
5. 登录后从新的一局开始，建议首次使用在人机对局确认提示。
6. 根据窗口建议在游戏中手动操作。结束后点击「停止并恢复」，或关闭教练。

本地代理证书用于读取游戏消息，启动时可能加入当前用户证书存储。启动流程会临时开启 TUN、切换规则模式并增加游戏进程分流，停止时恢复保存的网络配置。使用中请保持教练和 Clash 运行。

### 5. 背景与主题

深色、浅色、粉色配色会自动保存。背景收藏支持本地图片、动图、动态场景和碧蓝航线 Live2D。

发行包已包含背景目录清单和模型播放器。点击「下载并应用」时才下载对应资源，首次下载需要网络。模型、贴图和视频可能较大，请等待进度完成。视频使用静音循环播放，Live2D 需要显卡驱动支持 OpenGL。播放失败时可切回内置插画。

主题视频和游戏模型来自第三方资源服务，服务可用性与授权遵循各自项目。第三方角色资源按需下载。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 下载后找不到启动程序 | 下载 Releases 中的 win-x64.zip 附件，完整解压后打开 |
| 没有填写设置 | 左侧「连接设置」或小窗「主题 → 连接设置」中填写 |
| 找不到 Clash 配置 | 先打开 Clash 并启用一个配置，再选择含 clash-verge.yaml 的目录 |
| 提示找不到代理组 | 先停止并恢复，打开设置，读取当前配置的代理组并重新保存 |
| 找不到雀魂程序 | 从 Steam 的「浏览本地文件」进入游戏目录，选择游戏 exe |
| 启动失败或端口占用 | 先关闭其他 MAX、麻将助手，检查 23410、12121、12122 端口，再重试 |
| 登录后没有手牌 | 退出示例模式，开始新的一局。中途重连时可能要等待下一局 |
| 关闭时恢复失败 | 保持 Clash 开启，重新点击「停止并恢复」。保留 session.json 和 launcher-state.json 供恢复使用 |
| 动态背景失败 | 检查网络和显卡驱动，先选内置插画测试基础界面 |
| Windows 提示未知发布者 | 当前发行程序未作代码签名，请核对下载来源和 SHA256SUMS.txt |

启动与恢复状态、配色、角色搭配和背景缓存保存在解压目录。程序运行时不要移动目录或删除配置文件。分享日志前请检查其中的账号与对局信息。

更新教练时解压到新目录，先关闭旧版并完成恢复，再按需迁移连接设置与背景收藏。MAX 的正式版检查在空闲时自动进行。

## 从源码运行

开发环境需要 Windows x64、Python 3.12 和 Go。安装依赖并构建引擎后启动。

```powershell
py -3.12 -m pip install -r requirements.txt
cd MahjongCoach/engine-source
go build -o ../engine/mahjong-coach-engine.exe .
cd ../..
py -3.12 MahjongCoach/coach.pyw
```

实时数据需要 `MajsoulMax-Steam/app/MajsoulMax/MajsoulMax.exe`。开发时可从 [MAX 正式发行页](https://github.com/Avenshy/MajsoulMax/releases) 下载官方包，解压到该路径，并保留原压缩包以供版本识别。设置通过界面填写。

## 避四策略

点击「避四」后，教练会结合公开点数、分差和牌局阶段选择攻守，三麻显示为「避末」。

- 领先末位时限制进攻切牌的估计风险。对手立直或听牌威胁较高、自己的手牌收益不足时优先防守。
- 常规东风或半庄的后段，领先末位至少 8000 点时偏向保住分差。
- 落后时优先争取和牌脱离末位。后段落后至少 8000 点时，增加对打点的考虑。
- 领先时已有役的听牌倾向保留默听，也会减少主动开杠。
- 顶部说明当前名次、分差和选择理由。同点按危险侧处理。
- 点数缺失时提示等待新局，特殊赛制无法确认比赛长度时不启用后段分差规则。

这是可解释的规则策略，尚未经过大规模对战评测。它沿用当前引擎的风险估计，也会考虑牌效，效果取决于局面和估计准确性。合法和牌目前仍建议收下，暂未计算末局跳过和牌、流局结算及完整顺位期望。它不会显示未经校准的「第四率」。

## 如何理解概率

放铳风险根据公开弃牌、副露、巡目和立直状态估算。对手听牌概率与听牌条件下的牌种危险度相乘，再合并各家的估计。开局信息不足时显示「待估」。

危险牌列表用于辅助防守，具体等待牌仍需推测。概率尚未经过实战校准，少见牌型、对手打法和信息缺失都可能影响结果。

有效进张的未见张数包含可能在其他玩家手中的牌。和牌估分未必涵盖本场、供托、里宝牌及所有特殊役，实际点数以游戏结算为准。

实时辅助可能违反游戏平台规则。请自行了解平台要求及账号风险。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `coach.pyw`、`studio.py` | 桌面窗口、主题与牌面展示 |
| `backend.py` | 本地数据接收和启动恢复 |
| `presenter.py`、`strategy.py` | 出牌策略及中文提示 |
| `engine-source/` | 修改后的 Go 分析引擎 |
| `backgrounds.py` | 背景收藏 |
| `max_updates.py` | 正式版检查和更新 |

日志、账号会话、个人皮肤配置、代理配置及下载缓存均保存在本机。
